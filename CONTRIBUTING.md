# Contributing

Changes should preserve the source identity, network operationalization, random-comparator design, and claim boundaries.

## Scientific changes

If a contribution changes the projection rule, centrality rule, stress levels, random draw count, seed, efficiency metric, or quantile construction, update:

- empirical protocol;
- analysis plan;
- tests;
- derived evidence;
- report;
- figures.

Do not silently change the released estimand.

## Source integrity

Preserve the pinned Zenodo DOI, version, and MD5 unless making a documented release update.

Do not add synthetic fallback data.

## Construct discipline

Do not translate email connectivity directly into:

- knowledge;
- expertise;
- employee value;
- learning effectiveness;
- performance;
- replaceability.

## Random comparator

Random bands are empirical order-statistic diagnostics.

Do not label them confidence intervals or causal uncertainty intervals.

## L&D interpretation

Recommended actions should be framed as possible follow-up investigation or intervention categories rather than automatic prescriptions from network position alone.
